## Observation (not a regression) — fleet_p99 median with a partially-hot fleet — ADDRESSED

`Nodes.fleet_p99` was the **median** of live nodes' per-node p99s. With only one node hot
(`zeta` hashed to fathom1) and the others idle, `median([332.6, 0.0, 0.0]) = 0.0`, so the
p99-relative bar would be ~0 and flag nothing via the `threshold > 0.0` guard. Irrelevant to
the run itself — the rig (and the review's recommendation) uses the absolute floor path — but
the aggregator under-reported when a hotspot concentrated on a minority of nodes.

**Addressed 2026-07-08 (follow-up commit):** `fleet_p99` now aggregates only over nodes actually
serving load (`sample_count > 0`), **count-weighted**, so idle nodes can't drag the bar toward 0
and busier nodes count more. It's an approximation of the true pooled-distribution p99 (a
faithful merge would need per-node histograms — unwarranted for a fallback bar). The absolute
floor remains the recommended primary detector.
