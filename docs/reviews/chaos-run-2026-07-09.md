### 3. Per-finding live confirmation (rpc / SQL probes into the running fleet)

- **#4 — true pooled fleet p99 from merged histograms.** Under ~158 q/s of real Hrana load on
  `zeta` (hashed to fathom1), fathom1's beat published
  `q_hist={0,…,1,…}` (one count in the shard's q/s bucket), fathom2/fathom3 all-zero. The
  orchestrator read `Nodes.fleet_p99(60s, 1) = 199.0` — the **interpolated pooled percentile**
  of the merged histogram (`[100,200)` bucket), **not** fathom1's raw p99 (≈158–291), confirming
  the histogram-merge path replaced the old count-weighted mean.
- **#1 — dead-node reconciler consults the S3 lease.** Pinned `reconprobe → ghostnode` (a
  node_key that never beats). A forced `RebalanceJob` tick logged
  `rebalance: unpinned reconprobe — ghostnode not live (S3 lease free); re-homing` and left
  `Overrides.for_shard("reconprobe") == nil` — the dead-node → S3-`lease_holder` → free → unpin
  path, live. (The lease-held "keep pin (divergence)" branch stays unit-covered.)
- **#15 — pin canonicalization.** `Overrides.pin("TeStPin", "fathom3")` stored `shard_id=testpin`;
  `for_shard("TESTPIN")` found it; `LbMap.current()` rendered `testpin.<zone>` with no mixed-case
  key (would have dead-routed pre-fix). Unpinned cleanly.
- **#6 — ShardId gate at the command boundary.** `Commands.issue("../etc/passwd", …, "warm")`
  was rejected: `{"is not a valid shard id", []}` — a path-traversal id can't be persisted for a
  poller to hand to `WarmFollower`/`Shards.drain`.
- **#5 — `beat/1` preserves published stats.** After `Nodes.beat("probe5", q_hist: […])` then a
  liveness-only `Nodes.beat("probe5")`, the row still held `q_p99=42.0, sample_count=3,
  q_hist=[…1@idx3…]` — not NULLed (which would drop the node from the fleet bar).
- **#13/#14 — warm-location signal (age-sweep publish + `[:updated_at]` index).**
  `WarmLocations.warm_nodes(60s) = %{"zeta" => ["fathom3"]}` — the follower that never owned
  `zeta` advertised it warm+hot; owners correctly did not. The publish/retract runs each reporter
  tick over the new index with no error.
- **#11 / #12 (poller decouple + reporter batch) and #8 (emit-after-complete):** exercised
  implicitly by the clean loop below — every reporter tick published (beat + warm-locations) and
  every command completed without wedging or crash.
